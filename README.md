# Serein Frontend

React 19 + Vite frontend for the Serein restaurant reservation platform.

```bash
cp .env.example .env
npm install
npm run dev
```

Set `VITE_API_BASE_URL` to the backend API base (default `http://localhost:3001/api`).

The UI includes animated React Bits `CurvedLoop` text, an editorial restaurant landing page, account creation, sign-in, table reservations, and a personal booking dashboard.
